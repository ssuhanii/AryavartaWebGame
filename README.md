# Aryavarta

A 3D web game built with Vite and Three.js.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173` in your browser.

## 📁 Project Structure

```
web-game/
├── index.html      # Main entry point
├── main.js         # Game logic (Three.js)
├── style.css       # Styles
├── game.html       # Alternative game page
├── package.json    # Dependencies
└── assets/         # Game assets
```

## 🛠️ Tech Stack

- **Vite** — Build tool
- **Three.js** — 3D graphics library

## 📦 Dependencies

- `three` (^0.172.0)
- `vite` (^5.0.0)

## 🎮 Game Flow

This game serves as an entry point that leads to the main website running on a different localhost port. The main website contains all interactive maps and other learning features.

The main website is hosted in the **aryavarta website** repository.

```bash
# Build for production
npm run build
```
